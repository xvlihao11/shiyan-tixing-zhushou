# 实验提醒助手

一款面向沥青试验日常工作的 Android 助手，把样品管理、试验步骤、计时提醒、原始读数、结果计算、内控评价和报告导出集中在手机里。适合同时开展多个试验时记录进度、安排等待时间，并整理可追溯的试验记录。

## 主要用途

- **样品与试验记录**：按日期和样品管理试验，记录未老化、RTFOT 老化后、TFOT 老化后等阶段的数据，保存多组原始读数。
- **步骤计时与提醒**：自定义试验模板中的步骤、等待时间和提醒方式，使用闹铃或消息通知提示下一步操作；常用检测方案可一次建立多个项目。
- **结果自动计算**：支持常用项目的结果计算与修约，根据空容器、老化前和老化后质量计算质量损失；满足配对条件时计算老化前后的动力黏度比。
- **内控限值评价**：选择内控牌号并配置限值后，按匹配的试验项目、温度和老化阶段比较结果，显示合格或不合格，并在导出报告的主表中呈现评价。
- **照片留存与读数识别**：拍照或从相册添加仪器照片，关联到对应读数组；部分项目可使用云端识别，核对后再填入读数。
- **报告与备份**：按日期、样品和试验项目选择导出 Markdown 报告，支持完整 ZIP 备份与恢复，便于归档和迁移记录。
- **界面个性化**：支持图片、视频及 MPKG 壁纸，可调整玻璃卡片外观，壁纸随页面切换移动。

## 基本使用流程

建立样品 → 选择试验模板和内控牌号 → 按步骤计时并录入读数 → 查看计算结果与限值评价 → 导出报告或备份。

试验记录与计时功能在本机使用。云端照片识别需要自行配置火山方舟 API 密钥，识别时照片会发送到火山方舟服务，识别结果需要人工核对。仅填写“采用标准”的名称不会自动生成判定限值；评价依赖已配置并匹配的内控规则。

R25 更新：为沥青开口闪点增加 AS 2341.14:2013（保留国内规程），旧模板自动补齐，旧项目也可在参数中选择。选用 AS 2341.14 时报告结果修约至最接近的 10 ℃，原始仪器读数不变；闭口闪点不套用此方法。依据：https://austroads.gov.au/publications/pavement/atm-112

R24 更新：软化点、针入度模板保留原国内方法并补上 AS 2341.18:2020、AS 2341.12:2020 选项；旧实验可在参数中改选。澳标普通软化点按已记录浴液报告：水浴均值修约至 0.2 ℃、甘油浴均值修约至 0.5 ℃；浴液未选时不生成澳标软化点结果。国内软化点保留 R23 的两级 0.5 ℃修约，针入度维持均值取整。浴液随报告导出；已有实验所选规范不自动更改。编号依据 Austroads WEB-ASB-20，澳标软化点报告精度依据 Austroads AP-T379-25。

R23 更新：软化点普通测定先将每个仪器示数按 0.5 ℃修约（逢五取偶），再取算术平均值，最后将平均值修约至 0.5 ℃。例如 63.49、63.96 → 63.5、64.0 → 63.75 → 64.0 ℃。原始示数完整保留，旧记录、评价和新导出同步使用新算法。离析差值计算保持原样。

R22 修复：老化质量变化改为（老化后总质量－老化前总质量）÷（老化前总质量－空容器质量）×100%，增重为正、失重为负，单瓶显示三位小数。RTFOT 可手动填写修正系数 ΔF（百分点），默认 0，须按采用规程和海拔核对；旧称量记录直接重新计算，原始读数不变。单瓶结果不替代规程要求的两份试样平均报告结果。依据：https://xxgk.mot.gov.cn/2020/jigou/glj/202508/P020251031362168347304.pdf

R21 修复：同步最新源码后重新打包并逐项核对 APK 资源。已有实验重新导出时，动力粘度结果为整数、旋转粘度结果固定两位小数，原始读数不因导出而变化。旋转粘度照片识别保留原始数字与单位，核对后将 mPa.s / mPa·s 除以 1000 保存为 Pa·s，单位不明时需手动选择；不会自动猜测并改写旧记录的单位。
