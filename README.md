# 实验提醒助手

一款面向沥青试验日常工作的 Android 助手，把样品管理、试验步骤、计时提醒、原始读数、结果计算、内控评价和报告导出集中在手机里。适合同时开展多个试验时记录进度、安排等待时间，并整理可追溯的试验记录。

## 主要用途

- **样品与试验记录**：按日期和样品管理试验，记录未老化、RTFOT 老化后、TFOT 老化后等阶段的数据，保存多组原始读数。
- **步骤计时与提醒**：自定义试验模板中的步骤、等待时间和提醒方式，使用闹铃或消息通知提示下一步操作；常用检测方案可一次建立多个项目。
- **结果自动计算**：支持常用项目的结果计算与修约，根据空容器、老化前和老化后质量计算质量损失；满足配对条件时计算老化前后的动力黏度比。
- **内控限值评价**：选择内控牌号并配置限值后，按匹配的试验项目、温度和老化阶段比较结果，显示合格或不合格，并在导出报告的主表中呈现评价。
- **照片留存与读数识别**：拍照或从相册添加仪器照片，关联到对应读数组；部分项目可使用云端识别，核对后再填入读数。
- **报告与备份**：按日期、样品和试验项目选择导出 Markdown 报告，支持完整 ZIP 备份与恢复，便于归档和迁移记录。
- **界面个性化**：支持图片、视频及 MPKG 壁纸，可调整玻璃卡片外观，壁纸随页面切换移动。

## 基本使用流程

建立样品 → 选择试验模板和内控牌号 → 按步骤计时并录入读数 → 查看计算结果与限值评价 → 导出报告或备份。

试验记录与计时功能在本机使用。云端照片识别需要自行配置火山方舟 API 密钥，识别时照片会发送到火山方舟服务，识别结果需要人工核对。仅填写“采用标准”的名称不会自动生成判定限值；评价依赖已配置并匹配的内控规则。

修复模板温度已经填写却要在每个动力黏度项目重复输入的问题。新建项目会从模板读取温度，接受 60、60.0、60℃ 等常见写法。只有一个可选温度时直接带入；模板名称明确写了 60℃ 且可选温度含 60 时也直接带入。只有确有多个温度且无法由模板名称确定时才要求选择。若规范有多个候选项，仍要求选择规范，但不再重复询问唯一温度。

已有记录里“60℃”等可明确识别的温度会规范为数字“60”，以便项目温度数字框和内控温度匹配正确显示；空温度和无法确定的写法不会被猜测填充。动力黏度比配对及评价沿用 R16 的严格规则，撤回 R17 放宽配对的修改。壁纸、计时和实验读数未改变。
