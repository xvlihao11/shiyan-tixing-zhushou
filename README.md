# 实验提醒助手

一款面向沥青试验日常工作的 Android 助手，把样品管理、试验步骤、计时提醒、原始读数、结果计算、内控评价和报告导出集中在手机里。适合同时开展多个试验时记录进度、安排等待时间，并整理可追溯的试验记录。

## 主要用途

- **样品与试验记录**：按日期和样品管理试验，记录未老化、RTFOT 老化后、TFOT 老化后等阶段的数据，保存多组原始读数。
- **步骤计时与提醒**：自定义试验模板中的步骤、等待时间和提醒方式，使用闹铃或消息通知提示下一步操作；常用检测方案可一次建立多个项目。
- **结果自动计算**：支持常用项目的结果计算与修约，根据空容器、老化前和老化后质量计算质量损失；满足配对条件时计算老化前后的动力黏度比。
- **内控限值评价**：选择内控牌号并配置限值后，按匹配的试验项目、温度和老化阶段比较结果，显示合格或不合格，并在导出报告的主表中呈现评价。
- **照片留存与读数识别**：拍照或从相册添加仪器照片，关联到对应读数组；部分项目可使用云端识别，核对后再填入读数。
- **报告与备份**：按日期、样品和试验项目选择导出 Markdown 报告，支持完整 ZIP 备份与恢复，便于归档和迁移记录。
- **界面个性化**：支持图片、视频及 MPKG 壁纸，可调整玻璃卡片外观，壁纸随页面切换移动。

## 基本使用流程

建立样品 → 选择试验模板和内控牌号 → 按步骤计时并录入读数 → 查看计算结果与限值评价 → 导出报告或备份。

试验记录与计时功能在本机使用。云端照片识别需要自行配置火山方舟 API 密钥，识别时照片会发送到火山方舟服务，识别结果需要人工核对。仅填写“采用标准”的名称不会自动生成判定限值；评价依赖已配置并匹配的内控规则。

### R35
新增 MSCR 试验，位于统一实验类型列表，可编辑方法、温度、步骤及提醒。每组独立记录 Jnr₀.₁（kPa⁻¹）、Jnr₃.₂（kPa⁻¹）、蠕变恢复率 R（%），恢复率需选择 0.1 或 3.2 kPa 应力。保留仪器最终结果及原始小数位，三项不相互求平均，报告分三行列出。未自动套用产品合格限值；未新增 MSCR 照片自动识别。沿用现有独立包名和签名，可升级当前版本。

方法参考：交通运输部 [JTG 3410—2025 / T 0647](https://xxgk.mot.gov.cn/2020/jigou/glj/202508/P020251031362168347304.pdf) 第 6 章区分 R₀.₁、R₃.₂ 与 Jnr₀.₁、Jnr₃.₂；[ASTM D7405-24](https://store.astm.org/d7405-24.html) 方法范围为恢复率和不可恢复蠕变柔量测定。当前三项模式是用户要求的记录子集，不能替代完整规程报告。

### R36
按用户澄清，将 MSCR 第三项从恢复率 R 改为 Jnr diff（不可恢复蠕变柔量差异率）。输入 Jnr₀.₁、Jnr₃.₂ 后按 T 0647-10 的 `(Jnr₃.₂ − Jnr₀.₁) / Jnr₀.₁ × 100%` 自动计算至 0.1%，显示在第三个只读框。差异率不受 0～100% 限制；分母为 0 时无法计算。报告三项分别成行，差异率行保留计算式。R35 已填写的旧第三项及其应力另外留存，不能误作差异率。保留原始 Jnr 小数位、现有包名和签名。

### R37
收率预测中的实测模式改为通用的、按母油标识／批次及牌号隔离的分段线性插值。用户在界面新增并勾选实测切割点后自动更新曲线，无需修改代码。至少需要两个不同收率的同批点（可包括本次初始点）；更多点形成多段曲线。可正算针入度或反算收率，范围以所选实测点为界。缺少本批数据、数据趋势冲突或目标超出实测范围时提示补测，不再自动向历史经验公式收缩或兜底。其他母油、其他牌号和掺蜡记录不混入本批切割曲线。原经验公式仍供显式选择；原始记录保留。

新模式仅估算切割收率，不从切割点换算蜡油掺量；掺蜡数据需独立验证。两个点只给出局部线性估算，不能说明整个原料范围、其他试验条件或新母油的通用物性规律。回归测试包含不同母油、非等斜率三点、端点复现、正反算、跨批隔离和异常数据处理。用户给出的 40.83%/42、42.83%/70 只作为测试用例，不预置为生产实测记录。

### R38
收率实测曲线增加调配油标识与母油质量占比，支持常用 90∶10、85∶15、80∶20 及自定义比例。明确当前收率口径为 `沥青质量 /（母油质量＋调配油质量）×100%`。只有同牌号、同母油标识、同调配油、同质量配比且收率以混合总投料为分母的已选切割实测点参与当前曲线。

原实测点的数值不变，未记录配料条件的旧点不自动参与；用户可逐条点击“补充配料”，确认总投料口径并添加条件，修改历史单独留存。新记录保存当前配料条件，修改当前配料条件会清除旧预测显示。更换调配油或比例使用对应实测曲线，不从单一配比外推其他比例。已验证配比、油品、收率口径隔离，以及旧记录补充条件后的复用。

### R39
母油质量占比支持 100% 纯母油。此时调配油为 0%，无需填写调配油标识，收率分母等于母油投料质量；纯母油记录仅匹配相同母油、牌号和 100% 比例。切回混合配比后重新启用调配油标识。已验证纯母油计算、空调配油字段、旧残留调配油文字不影响纯母油匹配，以及与混合配料记录隔离。
