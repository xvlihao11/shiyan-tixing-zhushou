# 数据录入与手机传输

## 操作入口

样品 → 日期 → 样品：

- 每个项目右侧“录入数据”：录入原始读数；“步骤”：原有计时操作。
- “试验记录”：查看各步骤开始、计划到点、确认完成、跳过时间。
- “结果汇总”：查看各项目结果，以及条件和数据齐全的老化前后结果。
- 导出／传输统一放在首页“任务”的右上角，样品和项目页面不放传输出口。

底部导航保持原有五个按钮。列表显示“第 X/Y 页 · 跳转”，点页码输入数字直接到达指定页，不再用上页／下页按钮。分页控件与试验卡片分区放置。无需互联网或外部路由器。

## 数字录入

数字键盘为三列四行，带小数点、退格、清空、确认、确认并下一项。± 仅在温度和质量修正字段启用。数字原文最多15字符，零和空值不同；原始示数不会被计算或修约覆盖。

项目最多4组、每组最多6条读数。软化点固定2项；质量变化固定3项质量，另有修正值。组名可用拼音编辑，关联时组名应保持一致。每次确认都保存并读回校验，未确认的键盘内容不保存。

“参数／模式”中核对数据类型、单位、温度、采用规范、软化点模式与规则、对照项目。输入读数后不能直接切换黏度输入单位，以免相同数字被重新解释；请先清空或另建项目。规范按钮打开国内／澳洲规范选择页，并保留自定义编辑。针入度：JTG 3410—2025 / T 0604、AS 2341.12:2020；软化点：JTG 3410—2025 / T 0606—2011、AS 2341.18:2020。动力黏度：T 0620、AS/NZS 2341.2；旋转黏度：T 0625、AS/NZS 2341.4；RTFOT：T 0610、AS/NZS 2341.10；TFOT：T 0609。国内方法标注 JTG 3410—2025。没有已核实对应项的项目保留自定义，不捏造澳洲方法号。选择澳标软化点后必须再选择实际水浴／甘油浴，未选时不产生结果；选择国内软化点后联动0.5℃规则。旧版保存的“国内规程”标签可以在该页面重新指定具体规范。

## 计算

- 针入度：输入0.1 mm，均值修约至整数，逢五取偶。
- 国内普通软化点：每个示数先修约至0.5℃，再平均并修约至0.5℃，逢五取偶。
- 澳标普通软化点：原始示数直接平均，水浴修约至0.2℃、甘油浴至0.5℃。
- 离析：清楚区分上部、下部，取原始值绝对差，至0.001℃；不参与普通软化点老化差值。
- 动力黏度：输入单位可选Pa·s、mPa·s、P；本次单位下均值修约至整数。老化比值先统一为Pa·s后计算。
- 旋转黏度：输入单位可选Pa·s、mPa·s、P，统一成Pa·s，结果及报告保留0.001 Pa·s精度。区别于手机版当前两位小数的导出显示。
- 质量变化：输入空容器、老化前总质量（含容器）、老化后总质量（含容器）；(后−前)/(前−空容器)×100% + 修正值。正为增重，负为减重，显示三位小数。
- 其他数值：可编辑单位和修约步长，按均值计算；识别到延度时默认cm、步长1。专用项目（例如BBR）的独立算法不在本版中，应核对后使用专门的软件计算。

所有本组预设读数填齐后才出结果；可减少末尾空读数。零分母、未填写、错误数字不产生有效比值。

老化前后比较限定同一样品、组名、数据类型、规范和温度，RTFOT与TFOT分别对未老化比较。针入度比为后/前×100%；软化点变化为后−前，保留正负；黏度比为后/前，单位倍。候选对照重复时在参数中指定项目ID。

## 保存与归档

保留原有LAB3样品和计时布局，读数使用独立 results4c 命名空间，带版本、校验和、无损零字节压缩、读回核验。保留足够的内部存储条目供计时状态更新；剩余空间不足时拒绝新读数保存并提示，不宣称已经保存。删除板内项目后回收相应读数存储，TF上已经保存的历史文件保留。

TF目录：`/records/日期/sample-ID/`。已有的 run-ID.csv 为计时记录；新增 results-ID.csv 为试验数据表，results-ID.json 保留原始字段、阶段、单位、规则和步骤毫秒时间。正式文件替换前先写临时文件并逐字节读回，保留 .bak 上一版本。

缺卡时当前数据可保存在板内。重新插卡后约30秒尝试补同步；热点活动时推迟重新挂载，以免打断下载。板内仍有32样品、32项目的活动容量限制；TF归档不是无限数量活动项目数据库，也不会自动把已删除历史导入板内。

## 手机选择和下载

首页“任务”右上角 → 导出／传输。有两种操作：

1. “手机上选择”：开启热点，手机可以从全部现有活动样品中选择。不会预先下载全部项目。
2. 板子按“日期 → 选择样品 → 选择试验”逐层打开后勾选，再点“传输所选”：手机仅能看到该共享范围中的项目，还能继续细选。支持整日、整样品选择；切换其他日期时保留之前的勾选。

板子和手机默认全部不选。手机自动弹出选择页，或点系统的“登录此网络”提示。页面按 日期 → 样品 → 老化阶段 → 试验项目 展开；日期、样品、阶段可整组勾选，项目可单独勾选。显示已选数量，可全选或清空。步骤时间是独立选项，默认不附带。

手机点击“导出选中项目 .md”时，才按此次勾选生成并下载报告。针入度、软化点单独选中时，不会夹带黏度或其他项目。需要老化比值时手动勾入对应未老化项目；来源不完整则注明原因，不自动增加项目。

手机连接屏幕上的热点和密码，也可扫码连接。不需要路由器或互联网。连接后系统登录窗口不能下载时，使用右上角菜单“在浏览器中打开”；下载二维码和屏幕地址保留为备用入口。报告保存在TF的 /exports/ 目录。

热点运行与触摸采样分别处理。开启后可正常点底部“样品”或“任务”，不会被后台自动切回热点页。通过同一热点更新共享内容时保留当前连接和密码；关闭后重新开启会生成新密码。5分钟没有HTTP请求时自动关闭，也可在热点页手动关闭。

服务仅提供本次明确共享范围内的数据，按项目ID验证手机提交的选择，不列出其他卡内文件。当前为Markdown下载与分享，BLE接收和手机版可编辑数据导入属于后续扩展。

## 秒表与连续记录

进入“设置 → 秒表”（“设置时钟”页也有入口），点“开始”计时。点“记录”不会停止秒表，每次保存累计时间及本段用时：例如累计10秒、18秒、31秒，对应本段10秒、8秒、13秒。暂停期间不计入时长，点“继续”接着走。

右上角“记录”查看全部条目，上下滑动翻页，或点页码直接跳转。TF卡正常时记录从第一条保存为CSV，超过100条也能继续；内存只缓存最近100条。文件位于TF的 `/stopwatch/`，`total_us`为累计微秒，`interval_us`为本段微秒，除以1,000,000即为秒。容量受卡剩余空间和文件大小限制，不会覆盖旧记录。没有可用TF卡时最多暂存100条；卡恢复后，下次记录会先补存旧条目。新增写入失败会提示，计时继续。

显示到0.01秒，屏幕约每0.1秒刷新，不代表经过校准的测量精度。切换页面、锁屏和调整RTC不影响正在运行的秒表；仍保留30秒无操作锁屏。暂停后可“清零”，确认后清空本次列表，TF上的CSV保留。断电或重启会清零秒表和当前列表，无卡暂存记录会丢失；已经保存的CSV仍在卡上，暂不提供板上重新打开旧秒表会话的入口。
